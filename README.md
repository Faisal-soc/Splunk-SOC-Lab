Splunk SOC Lab

A hands-on SOC lab focused on security monitoring, log analysis, alert investigation, and incident detection using Splunk.

Tools

* Splunk Enterprise
* Splunk Universal Forwarder
* Windows 11
* Sysmon
* VMware

What I Built

* Configured a Windows endpoint to send security logs to Splunk.
* Collected Windows and Sysmon logs.
* Monitored security events and investigated alerts.
* Created searches and dashboards for SOC monitoring.
* Analyzed suspicious activity and investigated security events.

Security Monitoring

The lab covers monitoring and investigation of:

* Failed and successful logins
* PowerShell activity
* Suspicious processes
* New user creation
* Scheduled tasks
* Network activity

Objective

The goal of this project was to build practical SOC Analyst skills through a realistic security monitoring environment and hands-on investigation using Splunk.

Skills Demonstrated

SIEM | Log Analysis | Alert Investigation | Windows Security Monitoring | Sysmon | Incident Investigation | Threat Detection
